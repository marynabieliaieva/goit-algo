# goit-algo-hw-08

Домашнє завдання до тем 7 «Дерева та балансування» і 8 «Купи, або піраміди».

## Файли

- `avl_tree.py` — AVL-дерево з конспекту (вузол, повороти, вставка з балансуванням).
- `task1_min_value.py` — завдання 1: `find_min(root)` знаходить найменше значення в дереві.
- `task2_sum_values.py` — завдання 2: `sum_values(root)` знаходить суму всіх значень у дереві.
- `task3_cables.py` — завдання 3: `min_connection_cost(lengths)` знаходить мінімальні витрати на з'єднання кабелів за допомогою купи (`heapq`).

Запуск (Python 3.9+, без сторонніх бібліотек), з папки `hw_08`:

```bash
python task1_min_value.py
python task2_sum_values.py
python task3_cables.py
```

Кожен скрипт друкує результат і перевіряє його через `assert`.

## Як це працює

**Завдання 1.** У дереві пошуку менші значення завжди ліворуч, тому найменше значення — у крайньому лівому вузлі. Функція просто йде ліворуч, доки є лівий нащадок. Складність O(h), для AVL-дерева це O(log n). Для порожнього дерева повертає `None`.

**Завдання 2.** Рекурсивний обхід: значення вузла + сума лівого піддерева + сума правого піддерева. Складність O(n). Для порожнього дерева повертає `0`.

**Завдання 3.** Жадібний алгоритм на мінімальній купі: щоразу беремо два найкоротші кабелі, з'єднуємо їх, додаємо вартість до загальних витрат і кладемо новий кабель назад у купу. Довжина кабелю входить у витрати стільки разів, скільки з'єднань він пройшов, тому короткі кабелі вигідно з'єднувати першими. Складність O(n log n).

Приклад для кабелів `[4, 3, 2, 6]`:

| Крок | З'єднання | Вартість |
|------|-----------|---------:|
| 1    | 2 + 3     | 5        |
| 2    | 4 + 5     | 9        |
| 3    | 6 + 9     | 15       |
|      | **Разом** | **29**   |
