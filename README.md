Домашнє завдання до теми 2 «Основні структури даних». Потрібен Python 3.9+, сторонні бібліотеки не використовуються.

## Завдання 1. Черга заявок у сервісному центрі (`queue.Queue`)

```bash
python task1_service_center.py              # працює, доки не натиснути Ctrl+C
python task1_service_center.py --cycles 10  # 10 циклів і завершення
```

Структура відповідає псевдокоду:

- `queue = Queue()` — черга заявок;
- `generate_request()` — створює заявку з унікальним номером і додає її до черги;
- `process_request()` — якщо черга не пуста, видаляє й обробляє заявку, інакше повідомляє, що черга пуста;
- головний цикл виконується, поки користувач не вийде (Ctrl+C). На кожному кроці надходить від 0 до 2 нових заявок і обробляється одна, тому черга то росте, то спорожнюється.

## Завдання 2. Перевірка паліндрому (`collections.deque`)

```bash
python task2_palindrome.py
```

Функція `is_palindrome(text)` додає символи рядка (без пробілів, у нижньому регістрі) до `deque` і порівнює символи з обох кінців (`popleft()` і `pop()`). Якщо символів непарна кількість, середній залишається в черзі й не порівнюється. Тому функція коректно працює для рядків з парною та непарною довжиною і нечутлива до регістру та пробілів.

Приклади: `"А роза упала на лапу Азора"` і `"Never odd or even"` — паліндроми, `"Python"` — ні.
